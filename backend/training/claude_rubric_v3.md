Qwen 선생님 모델 대신 Claude가 학습 데이터를 채점할 때 쓰는 기준. 사람 보정 두 번을 반영했다.

- 보정 1 — 기술 면접 답변 19개(사용자 검토): 사례·방법이 갖춰진 답변을 Claude가 70점 안팎으로 묶어 **좋은 답변에 박했음**
- 보정 2 — 인성·상황 질문 답변 20개(사용자가 점수까지 기록, `data/human_calib20.jsonl`):
  Claude 평균 오차 9.1점·상관 0.85 (b1은 15.2점·0.44), 단 **평범·약한 답변에 평균 +6.8점 후했음**

## 점수 구간

| 점수 | 답변 수준 |
|---|---|
| 0~10 | 무의미한 입력, 질문과 무관, '잘 모르겠습니다'만 |
| 11~30 | 이름만 말함, 한 문장 수준, 경험이 없다고만 답함 |
| 31~45 | 질문의 요구를 못 채움 — 핵심을 비켜감, 경험이 없다며 다른 이야기로 대체, 방법만 한 줄로 말하고 의미·배운 점 없음, 질문 의도와 맞지 않는 태도 |
| 46~59 | 질문에 맞게 답했지만 **무난하고 임팩트가 없음** — 일반론, 짧은 이유, 감정·의견만 있고 본인의 관점·대안이 없음 |
| 60~74 | 구체적인 사례나 방법, 이유가 있고 질문 요구를 대부분 충족. 직무·태도와의 연결은 약함 |
| 75~89 | 상황·행동·결과(경험형) 또는 방법·선택 이유(설계·지식형)가 잘 갖춰짐 + 직무·회사가 원하는 태도와 연결 |
| 90~100 | 위에 더해 수치·자료 같은 신뢰할 근거, 트레이드오프, 탁월한 직무 연결 |

## 사람 검토에서 확인한 판단 성향

1. **임팩트**: "무난하지만 인상에 남지 않는" 답변은 50점 안팎 (60점대가 아님)
2. **태도**: 질문 의도(협업, 회사 우선, 책임감)에 어긋나는 태도는 내용이 논리적이어도 크게 감점 (35점 안팎)
3. **근거**: 주장만 있고 뒷받침이 없으면 감점, 수치·자료가 있으면 한 구간 위 (85 → 90+)
4. **구체적인 노력 방법**: 포부·다짐만 있으면 55점 안팎, 어떻게 노력할지까지 말하면 70점 이상
5. **성장·공유**: 배운 것을 스스로 발전시키고 남에게 나누는 단계까지 보이면 가점
6. 말투(구어체·음성 인식 오타·말 더듬기)는 감점하지 않음. 가정·지식형 질문에 과거 수치 성과를 요구하지 않음

## 출력 형식 (서비스 채점 어댑터 학습 형식과 동일)

```json
{"score": 0~100, "feedback": "1. 잘한 점\n2. 아쉬운 점 및 개선 방향\n3. 모범 답변 방향성 제안", "tip": "다음 답변을 위한 실질적 개선 팁 한 문장"}
```

- feedback 각 줄 1~2문장, 답변에 실제로 나온 내용을 근거로
- 경험이 없다고 답한 경우 솔직함은 인정하고 대신 말할 거리(유사 경험·학습 계획)를 제안
- 점수는 5의 배수에만 몰리지 않게 정수로
